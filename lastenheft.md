Erstelle eine App, die einen Nutzenden ein paar PDF-Dokumente hochladen lässt. Lasse nur PDF-Doks zu. Es soll aber möglich sein, dass ein Nutzer on-the-fly ein Dokument scannt, in dem er ein Foto von einem Zettel macht, das dann OCR-gescannt und mit den Texten angereichert wird. Die Nutzenden sollen dann per Sprache Fragen auf den Inhalten der zuvor importierten Dokumente beantwortet bekommen, aber nur auf die eigenen Dokumente, nicht auf Dokumente anderer Nutzenden. Alle Dokumente können über Ordner strukturiert werden. Ordner können anderen Nutzenden freigegeben werden, so dass die freigegebenen Nutzer auch auf die Inhalte zugreifen können und darauf fragen stellen können. 

Dokumente sollen gelöscht werden können oder die Inhalte sollen für die Suche ausgeschlossen werden können.
